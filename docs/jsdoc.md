# JSDoc 规范

适用范围：`src/**/*.ts`。

## 函数
- 导出函数必须包含 JSDoc。
- 必填标签：`@param`、`@returns`。
- 当函数可能抛出调用方需感知的错误时，补充 `@throws`。

## 导出常量/配置
- 必须说明：用途、单位、边界。
- 示例：超时使用毫秒（ms）；轮询上限需写明默认值与最大尝试次数含义。

## 类型别名/接口
- 说明语义与关键字段，避免仅重复类型字面值。

## 私有辅助函数
- 可简化为一段短注释，但必须说明输入/输出语义。

## 命名与风格
- 注释描述行为与约束，不写实现过程。
- 文案保持简短、可执行。
